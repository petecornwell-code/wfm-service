Close GAP 1 of `20-VERIFICATION.md` (success criterion 6, requirement SOLV-01): make the live
generate-timeslots endpoint read the desk's real anchor, prove the tiling refusal fires through
that endpoint, and close the precision hole in the replacement save-time gate.

Purpose: the verifier scored SC6 FAILED on two sub-claims. (1) `TimeslotController.generateTimeslots`
— a live REST endpoint already exposed by the frontend API client, whose entire purpose is the
generation this criterion names — still hands the generator a hardcoded midnight anchor instead of
the desk's own. Its sibling caller `FteUploadService` was fixed correctly; this one was not, and
the one test claiming to prove reachability documents in its own javadoc that it bypasses the
controller. (2) The replacement gate computes a minute-of-day from the hour and minute only, so a
value carrying a nonzero second or sub-second component passes the modulus and is persisted —
strictly weaker than the exact-equality check it replaced, and contradicting the criterion's
literal promise to refuse anything else by name. Both are latent only because every live desk is
anchored at `00:00` today; this phase's own final deliverable is what makes a non-midnight anchor
reachable for the first time.

Output: the generate endpoint anchored on the desk row, a test that drives the real controller
method on a re-anchored desk, and a save-time refusal that is not weaker than its predecessor in
any dimension.

**Recorded non-change.** `TimeslotGeneratorService.requireDayStartTiles` computes its own
minute-of-day from the hour and minute and carries the identical sub-minute blind spot. It is
deliberately left alone: after Task 2 no desk row can hold a day start with a sub-minute
component, so the generator's check can never receive one through the save-then-generate path, and
widening a second refusal in a gap-closure run would add untested surface with no reachable
caller. Recorded here so the next reader files it as a decision, not a missed site.
