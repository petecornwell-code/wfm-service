# Phase 12 Plan 01: End-to-End Atomic Shift Move Summary

Proved the atomic shift move end-to-end on the thinnest possible path: a single composite
`AssignSeatMove` group, generated by a new `MoveListFactory<Schedule>`, places a full 8-slot
contracted shift with a legally positioned 10:00 break on a previously empty agent-day, survives
a real local search under `EnvironmentMode.FULL_ASSERT` without corrupting the incremental score,
and composes with — rather than replaces — the existing change/swap move selectors.

## What Was Built

- **`ShiftWindowFinder`** (`src/main/java/com/wfm/solver/ShiftWindowFinder.java`) — a plain,
  Timefold-independent utility that indexes candidate seats by timeslot start time and walks
  contiguous spans of `requiredWorkSlots + breakSlotCount` (or just `requiredWorkSlots` when no
  break is required) present slots, trying break offsets in order until one satisfies alignment
  and the blocked-window margin. Mirrors `ScheduleConstraintProvider`'s own
  `expectedWorkSlots` (`RoundingMode.HALF_UP`), `exactlyOneBreak`'s threshold
  (`RoundingMode.CEILING`), `breakBlockedWindow`, and `breakStartAlignment`/`isAligned` arithmetic
  exactly, so a window it accepts is never subsequently rejected by the constraint provider. In
  this plan, `findWindows` returns at most one window (the earliest legal one); the list-returning
  signature lets 12-02 broaden to full enumeration without an API change.
- **`AssignSeatMove`** (`src/main/java/com/wfm/solver/AssignSeatMove.java`) — a package-private
  `AbstractMove<Schedule>` that brackets the single `agent` planning-variable write with
  `beforeVariableChanged`/`afterVariableChanged` and implements only
  `doMoveOnGenuineVariables`. Never overrides `createUndoMove` — deprecated for removal at
  1.16.0 and throws if invoked; the solver's `VariableChangeRecordingScoreDirector` generates the
  undo automatically. Implements `rebase`, `getPlanningEntities`, `getPlanningValues`, `equals`,
  `hashCode`, `toString` per the `Move` interface's own recommendation, even though the current
  simulated-annealing acceptor does not strictly require the Tabu-only methods.
- **`AtomicShiftMoveFactory`** (`src/main/java/com/wfm/solver/AtomicShiftMoveFactory.java`) — a
  public `MoveListFactory<Schedule>` with a public no-arg constructor (required for Timefold's
  reflective instantiation from the solver config). For each `AgentDayConfig` with zero existing
  assignments on that date, collects free seats where the agent holds the required specialization
  (primary or secondary, mirroring `specializationMatch`), delegates to `ShiftWindowFinder`, and
  wraps each returned window's seats into one `CompositeMove.buildMove(...)`. Read-only against
  `Schedule` — only `AssignSeatMove` mutates. Logs scan/generation counts at debug for later
  move-explosion diagnostics (Pitfall 4 in `12-RESEARCH.md`).
- **`solverConfig.xml`** — the `<localSearch>` block now declares an explicit
  `<unionMoveSelector>` containing `<changeMoveSelector/>`, `<swapMoveSelector/>`, and a
  `<moveListFactory>` pointing at `AtomicShiftMoveFactory` with `fixedProbabilityWeight` 1.0. The
  acceptor (`0hard/3000soft` simulated annealing) is unchanged.
- **`AtomicShiftMoveFullAssertTest`** (`src/test/java/com/wfm/solver/AtomicShiftMoveFullAssertTest.java`)
  — one test asserts `AtomicShiftMoveFactory.createMoveList` is non-empty and that
  `ShiftWindowFinder.findWindows` returns exactly the expected window (8 work seats, 10:00 break)
  for the 09:00–21:00 / 8h / 60-min-break / 1h-blocked fixture. A second test runs a real solver
  built with `EnvironmentMode.FULL_ASSERT`, a construction heuristic, and a local search whose
  move selector is the same union (change + swap + the new factory), asserting the solve
  completes without exception and assigns more than zero seats.
