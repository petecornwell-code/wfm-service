<objective>
Re-point the solver's own interval arithmetic, the one standalone utility that cannot reach a desk,
and the remaining direct calls in `SolverService` — then close the loop with D-07's third allowlist
section so that every midnight anchor left in production is named, reasoned, and inherited by Phase 20
as a work queue rather than a surprise.

Purpose: `ScheduleConstraintProvider` is the largest single call-site cluster in the phase, and the
one place where the anchor genuinely cannot reach some of its call sites. This plan makes which anchor
each constraint computes against visible at every call site, so the subset that is still on midnight
is a named symbol with a documented reason rather than an invisible default.

Output: the solver on the instance API, `FteSpreadsheetGenerator` allowlisted, and a two-directional
third guard scan.
</objective>

<p01_recap>
This plan executes P-01 from `19-01-PLAN.md` § planner_decisions. The verified facts it rests on,
so the executor does not re-derive them:

- `ScheduleConstraintProvider` brings `ScheduleConfig` into scope two different ways. Eleven
  constraints use `.join(ScheduleConfig.class)`, which puts `cfg` in the output tuple. Seven use
  `.ifExists(ScheduleConfig.class, filtering(...))`, which does not.
- Only two of the file's `DayWindow`-using paths sit in a stream that carries `cfg`:
  `shiftEnvelopeCompliance` (wired by the tracer, plan 19-03) and `breakClustering` (wired by plan
  19-04). Both are already done before this plan runs.
- All remaining `DayWindow` calls in the file sit either inside an `ifExists`-gated constraint's
  `.filter` (`breakBlockedWindow`, lines 383-399) or inside a helper reached only from such
  constraints: `countNonBreakHoles`, `slotMinutes`, `getGapLengths`, `findBreakStart`,
  `deriveIncrement`.
- Those streams cannot be converted to carry `cfg`. `exactlyOneBreak`, `breakBlockedWindow`,
  `breakStartAlignment` and `honourPreferredBreakTime` are already Quad, and the file's own javadoc
  at line 265 records that Timefold 1.16.0 has no Penta stream — which is why `ifExists` was chosen
  there originally. Restructuring the `groupBy` chain or adding the anchor to `AgentDayConfig` is a
  solver problem-fact change, which is SOLV-01's deliverable and is what the roadmap forbids
  combining with this phase.
- `getGapLengths`, `countContiguousGaps` and `findBreakStart` are package-private statics called
  directly from `MidnightGapScanTest`, a Phase 18 guard test criterion 4 requires stay green. Their
  signatures change, so that test's call shape changes with them.

The resolution: every helper takes a `DayWindow` parameter, so the anchor is explicit at every call
site. The `ifExists`-gated constraints pass one named, private, static, final midnight anchor with a
javadoc citing `SOLV-01` as the owner of its removal, and one allowlist entry covering it. Not
twenty-one scattered midnight literals — one named symbol Phase 20 deletes.
