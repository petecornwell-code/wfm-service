<shared_mechanics>
Every task in this plan performs the same three-step transformation. It is stated once here rather
than repeated per task.

1. **Bind once per scope.** At the top of each public method, or at the point the anchor source
   becomes available, create one `DayWindow` from the source named in the table below. Never bind
   inside a loop, and never bind a second window from a different source in the same class — plan
   19-04's SUMMARY records the bindings in `ShiftTemplateService`, `ShiftLibraryValidationService` and
   `ShiftLibraryGenerationService`, and plan 19-05's records the one in `ScheduleOutputService`; reuse
   those bindings rather than adding another.
2. **Route every midnight-implicit call through it.** The nine forms — `startMinute`, `endMinute`,
   `durationMinutes`, `isForwardWithinDay`, `overlaps`, `contains`, `startsBefore`, `toLocalTime`,
   `plusWithinDay` — each have an instance method with the identical parameter list, so the change is
   a receiver swap, not an argument change.
3. **Leave the five anchored primitives alone.** `startMinuteFromDayStart`, `endMinuteFromDayStart`,
   `timeAtDayStartOffset`, `businessDateOf` and `calendarDateAtDayStartOffset` stay public statics
   and stay correct. Where a file already calls them with an explicit `dayStart`, converting those
   calls to the bound instance is optional tidying — but if you convert any in a file, convert all of
   them in that file.
