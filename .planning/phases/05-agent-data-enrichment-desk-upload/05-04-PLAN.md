JSON contract — Plan 05's `client.ts` MUST update in lockstep.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | DoS | Excel upload — malicious zip-bomb / oversize file | accept | Apache POI 5.3 has built-in zip-bomb limits (POI's MAX_BYTES_TO_OPEN / OOXML default ratios). Existing upload endpoint does not add explicit MultipartFile size cap; this phase does not change that. ASVS L1 does not require explicit size limits; recommend follow-up if file-bomb DoS becomes a concern. Document as a known accepted risk in SUMMARY. |
| T-05-04-02 | Tampering | Header injection via crafted XLSX (e.g. header containing newlines/tabs) | mitigate | Header values are trimmed + lower-cased before comparison; only the lower-cased trimmed string is used as a Map key. The original string IS echoed back in the "Got headers: ..." error message — if an operator pastes a malicious header, it appears in the error response. Acceptable: the response is only seen by the same tenant's operator, and content is not interpreted (no HTML rendering of error body in the modal per UI-SPEC §4). |
| T-05-04-03 | Information Disclosure | Cross-tenant leakage in bulk PTO fetch | mitigate | New repository method scopes by deskId. Verify the existing tenant filter in DeskAgentService.listDeskAgentResponses propagates: the deskId argument is already verified to belong to the current tenant upstream. Test asserts no cross-tenant rows appear. |
| T-05-04-04 | Tampering | Path traversal via filename in Multipart upload | accept | DeskAssignmentUploadService does NOT use the filename for any filesystem operation — only reads from MultipartFile.getInputStream(). Filenames are not echoed back to other tenants. No mitigation required. |
| T-05-04-05 | Spoofing | XLSX content sniff (e.g. operator uploads a Word document with .xlsx extension) | mitigate | XSSFWorkbook will throw POIXMLException / InvalidFormatException on a non-XLSX file. The existing exception handler returns a 4xx with the underlying message; the modal will show the toast (errors stay as toasts per UI-SPEC §4). |
| T-05-04-06 | Elevation of Privilege | Bypass non-schedulable check via upload | mitigate | Both code paths (upload + manual) gate on AgentEligibilityService. Wave-0 tests assert both. Do NOT special-case admin override in this phase — that's a future per-agent override (Deferred Idea in CONTEXT.md). |
| T-05-04-07 | Information Disclosure | SkippedRow.reason echoing PII from spreadsheet (operator-supplied names) | accept | SkippedRow rows are returned only to the uploader (same tenant). Names are already in the spreadsheet they uploaded — no new disclosure. |
</threat_model>
