<objective>
Fix two bugs in infra/iam.tf, create infra/terraform.tfvars, then provision the GitHub OIDC identity provider and deploy role in AWS using a targeted Terraform apply.

Purpose: GitHub Actions needs to authenticate to AWS without long-lived credentials. The OIDC federation requires both an identity provider and an IAM role with the correct trust policy scoped to this specific repository. Two bugs exist in the current iam.tf that would cause security or runtime failures: (1) the trust policy uses `repo:*` which allows any GitHub repository to assume the role, and (2) the deploy policy is missing `cloudfront:ListDistributions` which deploy.yml calls dynamically to find the CloudFront distribution ID.

Output:
- infra/iam.tf with both bugs fixed (committed to git)
- infra/terraform.tfvars created locally (NOT committed — gitignored)
- aws_iam_openid_connect_provider.github, aws_iam_role.github_actions, and aws_iam_role_policy.github_actions provisioned in AWS
- Role ARN recorded (needed as GitHub secret AWS_DEPLOY_ROLE_ARN in Phase 4)
</objective>


    **Edit 2 — Fix Bug 2: Add cloudfront:ListDistributions (lines ~136-139)**

    Find the CloudFront statement block:
    ```hcl
      {
        Effect   = "Allow"
        Action   = "cloudfront:CreateInvalidation"
        Resource = aws_cloudfront_distribution.frontend.arn
      }
    ```

    Replace it with:
    ```hcl
      {
        Effect = "Allow"
        Action = [
          "cloudfront:ListDistributions",
          "cloudfront:CreateInvalidation"
        ]
        Resource = "*"
      }
    ```

    Note: `Resource = "*"` is required for `cloudfront:ListDistributions` because list operations
    cannot be scoped to a specific distribution ARN in IAM. `cloudfront:CreateInvalidation` can
    technically be scoped, but combining both under `*` is the standard pattern for CloudFront
    deploy roles and avoids a two-statement split.

    After editing, commit the fix to git:
    ```bash
    cd /Users/pete/IdeaProjects/wfm-service
    git add infra/iam.tf
    git commit -m "fix(iam): scope trust policy to petecornwell-code/wfm-service, add cloudfront:ListDistributions"
    ```
