# Phase 21 Plan 10: Anchored Allocation Grid and Business-Day Heading Disclosure Summary

**`ScheduleResults.tsx`'s allocation grid now routes every scheduling-time comparison, sort, containment test and subtraction through `frontend/src/utils/dayWindow.ts`'s branded `DayOffset` type in both render branches, fixing all seven confirmed overnight-fragmentation defects and adding a business-day calendar-span disclosure to the grid's section headings — verified by executing the real `dayWindow.ts` module against representative fixtures rather than a live browser render.**

## Performance

- **Duration:** ~50 min (approx.)
- **Tasks:** 3 of 3
- **Files modified:** 1

## Accomplishments

- `AgentAllocationTab` binds one `dayWindow = anchoredAt(schedule.dayStart ?? '00:00')` at the top of the function, threaded into both the slot-mode and shift-mode render branches (which both live inside the same closure). A payload carrying no anchor falls back to midnight, a provable no-op at that anchor.
- `timeDiffMinutes` and `addMinutes` are deleted entirely. Their one standalone call (the spec-filter `totalHours` sum) was converted immediately in Task 1; the four calls embedded inside the three break-band loops and the full-day loop were deliberately left broken, producing exactly 7 `TS2304` compile errors — confirming the compiler enumerated the remaining work rather than a reviewer's memory (full list below).
- The full-day regeneration loop now steps a bounded integer offset cursor from 0 to `anchoredEndMinute(endTime) - anchoredStartMinute(startTime)`, reading the window's end in an END position — the fix for a wrapping operating window that used to regenerate zero columns.
- A new `expandBreakSlots(window, breakStart, breakEnd, incrementMinutes)` helper, extracted once the same offset-cursor pattern was needed at three call sites (the day's `slotSet` build, and the per-entry `breakSlots` build in both the slot-mode and shift-mode branches). A break band crossing the anchor now expands to every slot it covers instead of looping zero times.
- Both slot sorts (`slots` in slot-mode, `shiftSlots` in shift-mode) order by `dayWindow.anchoredStartMinute` instead of lexically — an overnight shift's cells now form one contiguous run instead of splitting across the midnight boundary.
- The envelope-containment test uses `dayWindow.anchoredContains(envelopeStart, envelopeEnd, slot, slot+increment)` instead of raw string range comparison — an overnight envelope's hours are now marked covered instead of every column rendering as unreached.
- Shift-group ordering uses `dayWindow.anchoredStartMinute` instead of `localeCompare` on raw `HH:MM` — a night desk's earliest shift now sorts first.
- The unfilled-seat parser reads `v.businessDate`/`v.startTime` directly instead of splitting `timeslotLabel`, keyed on business date — closing the frontend side of the same post-midnight-shortfall gap 21-03 already closed on the backend's Excel export.
- A new `sectionHeading(date, dayStart)` / `shortWeekday(isoDate)` pair adds the locked business-day disclosure to both grid section headings, suppressed at a `00:00` anchor or an absent anchor, with `fontWeight: 600` added explicitly per the UI-SPEC's typography rule.
- All conversions are unconditional across both render branches, with no mode gate — confirmed by `grep -c 'schedulingMode ===' ` finding zero occurrences added by this plan.
