Purpose: SOLV-06 exists because of a specific property of this system — a constraint that matches zero
tuples scores identically to a satisfied one, so two different wrongnesses can sum to the same score.

one migration commit, and a failure that still names which constraint moved. BDAY-07 is the same
instrument pointed at a realistic desk shape rather than a property-chosen scenario.

Output: a per-constraint match-count table that is complete by reflection and asserts anchor invariance
(red until the migration lands), and a 48-agent Phil-US-shaped drift guard with a literal baseline
captured before the migration (green before and after).
