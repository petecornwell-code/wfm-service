<planner_decisions>
- **P-08 — an unset weekday exports its resolved effective value, never a blank cell.** Verified
  against the parser: `DeskAssignmentUploadService.parseDayCell` fails a blank or missing day cell
  with reason "is blank" and the caller then skips the entire agent row (D-04/WR-01). Exporting a
  blank for a not-set weekday would therefore make the round trip drop the agent, which is worse
  than the defect this phase closes. This matches 13-UI-SPEC.md Section 5's instruction that export
  cells mirror the Section 3 display rules, whose rule 5 renders the resolved default.
  **Documented consequence:** the round trip is lossless in *effective hours*, not in *row presence*
  — re-uploading an export materialises an `agent_day_hours` row for a weekday that previously had
  none. Reversibility: reversible.

- **P-09 — the seven day columns are inserted immediately after "Effective Contracted Hours Per
  Day", per 13-UI-SPEC.md Section 5, which shifts the two trailing identity columns to the right.**
  This is an operator-visible change to a file format, so it is pinned by a full-header-row
  assertion rather than left implicit. Reversibility: **costly** — per CONTEXT.md D-02, once
  operators round-trip against this shape, changing the column set again breaks their saved
  workbooks.
</planner_decisions>
