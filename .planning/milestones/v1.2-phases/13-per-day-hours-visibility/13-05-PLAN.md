<planner_decisions>
- **P-12 — the bulk out-of-range message is a toast, not an inline element, and drops the picklist
  clause.** The per-cell combo's Copywriting Contract sentence is
  `Enter a number from 0 to 24, or choose PTO / MANDATORY / Not set (default).` That sentence is
  false copy for the bulk control, which is a bare `<input type="number">` with no datalist and no
  PTO/MANDATORY/not-set options. The bulk guard therefore uses the truncated sentence
  `Enter a number from 0 to 24.` delivered through the file's established
  `showToast('error', …)` convention. Rendering it inline instead would add a second line beneath the
  input and break the already-verified E5 overflow truth ("single-line action row … no overflow path
  exists"). Reversibility: reversible.

- **P-13 — the muted collapsed treatment triggers only when all seven weekdays are unset, never on
  a partial week.** A partially-uploaded agent's summary legitimately mixes stored and resolved
  values, and 13-UI-SPEC.md E1 partial (already verified) says the resolution happens *before*
  min/max so the summary spans all 7 values. Muting a partial summary would assert "nothing was
  uploaded" about an agent who did upload, which is the same misrepresentation gap 1 exists to fix,
  inverted. Reversibility: reversible.

- **P-14 — the all-not-set predicate is extracted once and used twice rather than duplicated.** The
  expression already exists inline at the expanded-row empty-state note; the collapsed cell needs
  the identical condition. Two copies of one predicate is exactly the drift UPL-09 and D-06 exist to
  prevent, at UI scale. Reversibility: reversible.

- **P-15 — correcting an already-executed plan is done as a marked correction, not a silent
  rewrite.** The `13-04-PLAN.md` edit carries an inline `corrected by 13-05` marker so the planning
  record shows a correction happened rather than pretending the original text was always right.
  Reversibility: reversible.
</planner_decisions>
