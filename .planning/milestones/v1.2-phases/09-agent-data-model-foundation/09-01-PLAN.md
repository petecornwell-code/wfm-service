<objective>
Establish the name half of the Agent data-model foundation: the single shared `AgentNameSplitter` utility that implements the D-06 first-whitespace split rule, and the new `firstName` / `lastName` scalar columns on `Agent`. This is the contract every downstream write-site (BambooHR refresh, upload, and the one-time Flyway migration) reuses so the split rule is defined once, not hand-copied.

Purpose: MDL-01 requires first and last name stored as separate fields. Defining the split rule as one tested utility (per RESEARCH Pitfall 5 / Don't-Hand-Roll) prevents SQL-vs-Java drift when Plan 09-04 wires the write-paths and Plan 09-06 writes the migration.
Output: `AgentNameSplitter` + test, `Agent.firstName`/`Agent.lastName` + persistence test.
</objective>
